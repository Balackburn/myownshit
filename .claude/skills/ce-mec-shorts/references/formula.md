# Script formula (French) — "Ce mec…"

Write in **spoken French**, everyday register, past tense (passé composé). Short sentences.
The narrator is deadpan and fed up, as if telling something completely normal.

## 1. The 8 beats (adapted from the reference analysis)

| # | beat | French pattern | example |
|---|---|---|---|
| B1 | HOOK (0–3 s) | **Ce mec a [verbe] [objet banal] pour [but banal].** | *Ce mec a utilisé un aspirateur pour ranger sa chambre.* |
| B2 | RESULT | *Ça a marché.* / immediate consequence, ≤ 5 words | *Il a aspiré le chat.* |
| B3 | TURN | **Puis / Ensuite** + unexpected element | *Puis le chat a porté plainte.* |
| B4 | QUALIFY | **C'était [terme juridique].** / absurd "logical" observation | *C'était une séquestration.* |
| B5 | INSTITUTION | **Alors ce con a appelé les flics / porté plainte / pris un avocat.** | |
| B6 | ESCALATION | disproportionate response: *Ils ont envoyé le GIGN. / Un hélicoptère. / Leurs deux meilleurs hommes.* | |
| B7 | TWIST | reversal: the man is convicted, sold, adopted, takes off; or a reveal (*C'était [personnage culte]. Depuis le début.*) | *Le juge était aussi un chat.* |
| B8 | TAG | dry everyday detail, ≤ 7 words, then a silent hold | *Le chat a gardé la chambre.* |

You can merge B4 into B3 or drop it, or chain two escalations. Never more than 11 sentences.

## 2. Language rules
- **Opener**: always *"Ce mec…"* (the "This man" equivalent). Variants for a series: *"Ce type…"*, *"Ce gars…"* (rarely).
- **Connectives**: *Alors* (= "So", the causal engine, 2–3 per script), *Puis* / *Ensuite* (= "Then", 1–2). Avoid *et donc*, *du coup* (too chatty).
- **Swearing (deadpan — the contrast makes it funny)**:
  - *ce mec*: the opener, plus sometimes again in the middle (*Ce mec a quand même…*).
  - *ce con*: replaces "he" **once** at the stupidest beat (usually B5: *Alors ce con a appelé les flics.*).
  - *putain*: **once**, in the climax zone (B6–B7) or in a quoted dialogue line: *« Putain, mais qui éteint la lumière ? »*.
  - Allowed reserve (max 1 more): *bordel*, *merde*, *connard*, *abruti*, *nom de Dieu*, *bordel de merde*, *sa mère*, *putain de [nom]*.
  - **Target 2–3 swears per video**, never two in the same sentence (except a dialogue line), never in B1 apart from "Ce mec".
  - No slurs targeting a group (origin, religion, sexuality, disability…): the humour comes from the absurdity, not from punching down.
- **Dialogue line (optional, 1 max)**: in quotation marks, spoken by a character (a different voice in TTS if available). That's where *putain* hits hardest.
- **Numbers**: write them as digits in captions when they're the gag (*60*, *30*, *5 euros*, *20 ans*) and highlight them.
- **Legal vocabulary FR**: violation de domicile, effraction, séquestration, outrage à agent, délit de fuite, recel, abus de bien social, tapage nocturne, refus d'obtempérer, harcèlement, contrefaçon, usurpation d'identité, garde à vue, comparution immédiate, sursis, dommages et intérêts, frais de justice, pension alimentaire, perpétuité, travaux d'intérêt général, l'amende.
- **French institutions**: les flics, la BAC, le GIGN, le RAID, les pompiers, le SAMU, la préfecture, le tribunal, le juge, l'huissier, le fisc, la CAF, Pôle emploi / France Travail, la mairie, la SNCF, La Poste, the 17 (police) / 18 (pompiers).
- **Highlights**: 1–2 words per sentence, the nouns that carry the joke (`"highlight": ["chat","plainte"]`).

## 3. Writing checklist
- [ ] B1 states in < 3 s an object and a goal that are **both ordinary**; the absurdity comes from the combination.
- [ ] Every sentence follows **mechanically** from the previous one (if I remove one, the logic breaks).
- [ ] At least one institution or bureaucratic procedure.
- [ ] At least one inanimate object or animal treated as a legal person.
- [ ] A twist (B7) the viewer doesn't see coming, but that is logical in hindsight.
- [ ] The tag (B8) is shorter than the twist and petty/everyday.
- [ ] 2–3 swears, well placed. Read it aloud deadpan: does it work without any intonation?
- [ ] 8–11 sentences, 16–24 s.
- [ ] Every sentence can be shown by **one simple shot** with the available props/sets/creatures (otherwise add a prop or rewrite).

## 4. Premise bank (hooks B1 + direction)
1. …utilisé un aspirateur pour ranger sa chambre → aspirates the cat → cat lawsuit → cat judge.
2. …mis son micro-ondes en turbo pour réchauffer un café → the coffee leaves → hit-and-run.
3. …peint sa maison en vert pour qu'elle passe inaperçue → nobody finds it again, not even his wife.
4. …acheté un réveil très puissant → the sun rises at 3 a.m. → the préfecture demands an explanation.
5. …mis trop de parfum pour un rencard → the bees elect him queen.
6. …pris l'ascenseur pour le 3e → it doesn't stop → NASA → dropped off on the "3rd floor" of Mars.
7. …demandé à son chien de rapporter le journal → it brings back the journalist → kidnapping.
8. …installé une caméra pour surveiller son frigo → films himself sleepwalking → files a complaint against himself.
9. …mis un épouvantail dans son jardin → the crows hire a lawyer → harassment.
10. …acheté un GPS pour ne plus se perdre → the GPS takes him to the GPS's house → it is now his landlord.
11. …mis un aimant sur son frigo → the fridge sticks to the neighbour's car → recel (handling stolen goods).
12. …secoué une bouteille de soda pour l'ouvrir → he takes off → controller at Orly → speeding in a 30 zone.
13. …ri trop fort au cinéma → the film stops → the actors come out of the screen → noise complaint.
14. …tondu sa pelouse à 6 h du matin → the grass files a complaint → work-for-the-community: watering.
15. …offert des fleurs à sa voisine → her husband was a florist → unfair competition.
16. …tapé son ordinateur pour qu'il marche → the PC hits back → self-defence.
17. …jeté une pièce dans une fontaine → the fountain wants a cheque → overdraft fees.
18. …congelé ses restes → a mammoth in the freezer → the museum demands it back.
19. …crié « Marco » à la piscine → Polo actually came → the Italian embassy.
20. …mis son téléphone en mode avion → the phone takes off → Air France → missing passenger.
21. …mangé le yaourt de son coloc → the yaourt had a GPS tracker → the RAID.
22. …utilisé un sèche-cheveux pour sécher son chat → the cat inflates → flies off → the "cat-blimp" sells advertising.
23. …éternué dans un ascenseur → the virus files a complaint for eviction.
24. …garé sa voiture sur une place handicapé → the car is now in a wheelchair.  ⚠ avoid: punches down → **rejected**, an example of what NOT to write.
25. …appelé le service client → put on hold → retires on hold → the bank still calls him "Monsieur" every month.

## 5. Ten complete scripts (ready to storyboard)

**A. L'aspirateur** (≈ 18 s)
Ce mec a utilisé un aspirateur pour ranger sa chambre. / Ça a marché. / Il a aspiré le chat. / Le chat a porté plainte. / Pour séquestration. / Alors ce con a pris un avocat. / Putain, c'était aussi un chat. / Le juge aussi. / Quinze ans ferme. / Le chat a gardé la chambre.

**B. Le café turbo** (≈ 17 s)
Ce mec a mis son micro-ondes en mode turbo pour réchauffer un café. / Le café est devenu si chaud qu'il a quitté la tasse. / Puis l'appartement. / Il a pris un taxi. / Sans payer. / Alors ce con a appelé les flics. / Ils l'ont arrêté pour complicité. / Le café, lui, court toujours.

**C. Le chien et le journal** (≈ 19 s)
Ce mec a demandé à son chien de rapporter le journal. / Le chien a rapporté le journaliste. / C'était un enlèvement. / Le journaliste a porté plainte. / Le chien a pris six mois avec sursis. / Mais putain, c'est ce con qui paie. / Maintenant il doit promener le journaliste. / Deux fois par jour.

**D. La caméra du frigo** (≈ 20 s)
Ce mec a installé une caméra pour surveiller son frigo. / La nuit, quelqu'un a mangé ses yaourts. / Il a regardé la vidéo. / C'était lui. / Somnambule. / Alors ce con a porté plainte. / Contre lui-même. / Les flics l'ont arrêté. / Putain, il se rend visite au parloir. / Il s'apporte des yaourts.

**E. L'épouvantail** (≈ 17 s)
Ce mec a mis un épouvantail pour faire peur aux corbeaux. / Ça a marché. / Trop bien. / Les corbeaux ont pris un avocat. / Pour harcèlement. / Le juge était un corbeau. / Ce con paie maintenant une pension. / Putain, ils sont quarante.

**F. Le réveil** (≈ 18 s)
Ce mec a acheté un réveil très puissant pour se lever à l'heure. / Il a sonné. / Le soleil s'est levé. / À trois heures du matin. / La préfecture a exigé des explications. / Alors ce con a appuyé sur snooze. / Putain. / Il fait nuit depuis neuf minutes. / Ça fait trois ans.

**G. Le parfum** (≈ 18 s)
Ce mec a mis du parfum pour impressionner une fille. / Beaucoup trop de parfum. / Une abeille l'a suivi. / Puis tout l'essaim. / Elles l'ont élu reine. / Ce con pond des œufs maintenant. / Putain, quarante par jour. / La fille a épousé l'apiculteur.

**H. Le GPS** (≈ 17 s)
Ce mec a acheté un GPS pour ne plus se perdre. / Le GPS l'a emmené chez le GPS. / C'était une violation de domicile. / Le GPS a appelé les flics. / Ils ont envoyé le GIGN. / Ce con a dû payer les dégâts. / Maintenant le GPS est son propriétaire. / Le loyer est recalculé à chaque virage.

**I. La pièce dans la fontaine** (≈ 16 s)
Ce mec a jeté une pièce dans une fontaine pour faire un vœu. / La fontaine a refusé. / Pas assez. / Alors ce con a fait un chèque. / Il était en bois. / La fontaine a appelé la banque. / Putain, frais de rejet : quarante euros. / Son vœu était d'être riche.

**J. L'ascenseur** (≈ 18 s)
Ce mec a pris l'ascenseur pour monter au troisième. / L'ascenseur ne s'est pas arrêté. / Il a traversé le toit. / Puis l'atmosphère. / La NASA l'a contacté. / Ce con a demandé le troisième. / Ils l'ont déposé sur Mars. / Au troisième étage. / Il n'y a pas d'escalier.
